# Yui Portfolio（リニューアル版）

`Yui_Portfolio_リニューアル実装指示書.md` に沿って新規構築したポートフォリオサイトです。
「海・空・雲」の世界観で、自己紹介・対応できること・制作実績・お問い合わせまでを1ページにまとめています。

## 動作確認方法

`index.html` をブラウザで直接開けば確認できます（サーバー起動は不要）。
ウィンドウ幅 375px / 768px / 1024px / 1440px 程度でレイアウト崩れ・横スクロールが出ないかを確認済みです。

## 今回プレースホルダーのまま実装した箇所（要確認）

指示書の方針に従い、内容が確定していない部分は **推測で埋めず** `[〜を記載]` の形のプレースホルダーにしています。ご確認のうえ、下記を教えてください。

### プロフィール（自己紹介セクション）
- 本人写真（`assets/images/profile/` に配置予定。ファイルをいただき次第、`index.html` の `.about__photo` 内 `img-placeholder` を `<img>` タグに差し替えます）
- 自己紹介文の本文（旧サイトの文章をそのまま使うか、書き直すか）
- 得意な業種／好きなデザインテイスト／仕事で活かせる経験／今後目指していること

### 対応できること・使用ツール
- 各スキルカードの「概要」「対応範囲」の文言
- 各ツールの「状態」（使用可能／学習中／今後習得予定）と「用途」

### 制作実績（WORK 01〜03、`index.html` と `works/work-0X.html` の両方）
- 作品名・種別・案件区分・業種・制作目的・ターゲット・担当範囲・使用ツール・制作期間・工夫したポイント
- PC画面／スマホ画面のキャプチャ画像（`assets/images/works/` に配置予定）
- 公開URL（決まり次第、「サイトを見る」ボタンを有効化します。現在は無効表示です）

### お問い合わせ
- クラウドワークス／ランサーズ／SNS／お問い合わせフォームのURL
  - `index.html` の `.contact__links` 内、該当する `<a>` タグの `href` を実際のURLに変更し、`data-empty="true"` を削除すると表示されます

### その他
- `<title>` / `meta description` は指示書の仮案をそのまま使用（第16章）
- OGP画像・favicon は仮のシンプルなSVGのみ（本番用に差し替え可能）

## デザイン上の注意点

- ファーストビューは、旧ポートフォリオの背景写真（`sozai/new.png`／海を望むデスクのワークシーン、人物なし）＋ノートPC画面への実績スクリーンショットのはめ込み（射影変換）＋万年筆の手書きアニメーションを移植しています（`js/hero.js`）。
- 背景写真の比率（1536:1024）に合わせてヒーローの高さを決めているため、指示書 第6-2章の「スマホで85svh前後」という高さの目安とは異なります（写真のトリミングでPC画面や余白が欠けないようにするため）。
- ヒーロー下部の3層波アニメーション（`.wave-layer-track`）は指示書どおり維持し、写真の下端に重ねています。
- すべてのアニメーションは `prefers-reduced-motion: reduce` の環境では自動的に停止します。
- 制作実績・自己紹介の画像は、差し替えるまで点線枠のプレースホルダーで表示されます。

## 旧ポートフォリオについて

`portfolio/Yui_hidamari_Portfolio.dc.html` は、ファーストビュー（背景写真・PC画面はめ込み・手書きアニメーション）のみ本サイトに移植しました（2026-08-11）。移植元の素材は `sozai/new.png`・`sozai/lp_full_desktop.png`・`sozai/pen_quill.png`・`AsWinterBegins.otf` としてコピーしています。それ以外のセクションは指示書の推奨ファイル構成（第15章）に沿って新規構築したままです。今後の制作は本ファイル（portfolio2）をベースに進めます。
